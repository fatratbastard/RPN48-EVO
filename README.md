# RPN48 EVO
RPN Shell for the TI 84 EVO written in TI Basic

## Why?
Because I have a sickness called "I can't help but buy calculators." Woot had the new TI-84 EVO on sale so here we go.  Ostensibly bought it for Thing 2’s use for her Engineering degree, but she wants to stick with her N-spire. At least that’s what I told the wife when the package arrived.

## That didn’t answer the question about why RPN?
I've used RPN machines so much I'm damn near functionally illiterate using algebraic input (which is handy since algebraic input should only be used by toddlers).  This seemed like a good project to flex the old programming skills at. By which I mean I told Geoff Peterson Jr what I wanted and he went to town.

## Why not just use an existing package?
Couldn’t get anything I found to run on the EVO. It looks like its Python, TI Basic or nothing at the moment. If the machine ever get’s jailbroken I’ll try to write a shell that runs a little closer to the metal. This TI Basic version isn’t exactly fast.
